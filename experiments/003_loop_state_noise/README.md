# Эксперимент 003: зашумление состояния между loops

## Мотивация и гипотеза

В Experiment 001 поздние обновления становятся почти коллинеарными с текущим
hidden state, а в Experiment 002 dropout улучшил PPL на обученной глубине, но
усилил деградацию при дополнительных loops. Проверяем, может ли небольшой
случайный сдвиг после каждого завершённого прохода выводить recurrent dynamics
из узкой траектории и заставлять общий блок учиться исправлять локальные
возмущения.

Наивный аддитивный шум опасен: его абсолютный масштаб зависит от растущей нормы
residual stream, а накопление радиальной компоненты может сделать 16 loops
нестабильными. Поэтому основной вариант использует norm-preserving noise:

1. Gaussian-вектор ортогонализуется относительно состояния каждого токена;
2. его RMS нормируется и умножается на `sigma * RMS(h)`;
3. зашумлённое состояние проецируется обратно на исходную RMS-сферу.

Таким образом шум исследует направление hidden state, не изменяя его RMS.
Шум действует только во время обучения, плавно разогревается первые 30 шагов и
добавляется между loops. После последнего loop он по умолчанию не добавляется:
там он уже не может породить дополнительное вычисление и превращается только в
шум перед LM head.

## Матрица эксперимента

Все варианты имеют 5.67M параметров, два общих Qwen3-слоя, 16 train loops и
одинаковый бюджет не более 10M токенов.

| Вариант | Шум | sigma | Стабилизация |
|---|---|---:|---|
| `control_r16` | нет | 0.00 | контроль |
| `relative_s003_r16` | Gaussian | 0.03 | масштаб относительно token RMS |
| `spherical_s003_r16` | Gaussian | 0.03 | tangent noise + сохранение token RMS |

Оценка выполняется детерминированно при 1, 2, 4, 8, 12, 16, 20, 24 и 32 loops.
Для каждого числа loops сохраняются loss, perplexity, относительное обновление,
норма hidden state и cosine similarity с предыдущим состоянием.

## Критерий результата

Главная метрика — PPL@16 относительно `control_r16`. Признаком действительно
полезной recurrent dynamics считается не только улучшение PPL@16, но и более
плоская или улучшающаяся кривая PPL на 20–32 loops без роста hidden norm.
Если PPL@16 улучшится, а extrapolation ухудшится, шум следует интерпретировать
как обычную регуляризацию фиксированной глубины, как dropout в Experiment 002.

## Запуск

Из корня репозитория:

```bash
python experiments/003_loop_state_noise/run.py --variant control_r16
python experiments/003_loop_state_noise/run.py --variant relative_s003_r16
python experiments/003_loop_state_noise/run.py --variant spherical_s003_r16
python experiments/003_loop_state_noise/summarize.py
```

Для продолжения прерванного обучения добавьте `--resume`. Для оценки готового
checkpoint используйте `--eval-only`. Colab-процесс полностью собран в
[`experiment_003_colab.ipynb`](experiment_003_colab.ipynb).

Финальная ячейка ноутбука создаёт `experiment_003_results.zip`. Архив содержит
JSON/CSV результатов, training logs, конфиги и сведения о runtime; веса по
умолчанию не включаются, чтобы архив было удобно передать для анализа.
