# Эксперимент 001: масштабирование обновления между итерациями

## Гипотеза

При многократном применении одного блока Qwen3 остаточное состояние может расти слишком быстро. Проверяем, поможет ли масштабирование обновления

$$
h_{t+1}=h_t+\alpha\bigl(F(h_t)-h_t\bigr)
$$

использовать больше итераций без деградации качества.

Сравниваются три модели с одинаковой архитектурой (5,67 млн параметров, 2 общих слоя, 8 итераций) и бюджетом до 10 млн обучающих токенов на запуск:

- `baseline_r8`: обычное обновление, `α=1`;
- `fixed_05_r8`: фиксированное `α=0.5`;
- `learned_shared_r8`: один обучаемый `α`, инициализированный значением `0.5`.

## Результаты

Все модели обучались с 8 итерациями и оценивались с 1, 2, 4, 8, 12 и 16 итерациями.

| Вариант | Итоговый α | Потеря@8 | PPL@8 | PPL@16 |
|---|---:|---:|---:|---:|
| `baseline_r8` | 1.0000 | **7.0257** | **1125.2** | **1145.8** |
| `fixed_05_r8` | 0.5000 | 7.0548 | 1158.4 | 1182.5 |
| `learned_shared_r8` | 0.5038 | 7.0543 | 1157.8 | 1181.8 |

Лучший результат показал контроль на 8 итерациях. После 8 итераций качество всех вариантов ухудшается. Фиксированный коэффициент уменьшает норму скрытых состояний, но не устраняет почти коллинеарные обновления поздних итераций. Обучаемый коэффициент почти не изменился относительно инициализации. Следовательно, одного общего коэффициента остаточного обновления недостаточно для преодоления насыщения.

Полные метрики находятся в [`results/summary.csv`](results/summary.csv).

## Запуск

Из корня репозитория:

```bash
python experiments/001_skip_connections/run.py --variant baseline_r8
python experiments/001_skip_connections/run.py --variant fixed_05_r8
python experiments/001_skip_connections/run.py --variant learned_shared_r8
```

Для продолжения прерванного обучения добавьте `--resume`. Только оценка существующей контрольной точки запускается с `--eval-only`.

После получения трёх JSON соберите итоговую таблицу:

```bash
python experiments/001_skip_connections/summarize.py
```

Checkpoints сохраняются в `outputs/experiments/001/`, а JSON и CSV — в `experiments/001_skip_connections/results/`. Директорию `outputs/` не следует коммитить в GitHub.
